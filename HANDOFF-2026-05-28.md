# Truegle — Session Handoff 2026-05-28

## What Was Built This Session

### 1. Brand Transition — "AI" Removed from All User-Facing Text
Every visible "AI" label has been replaced across the entire frontend:
- Summary cards → "(Unbiased) Search Summary" / "Perspective Search Summary"
- Chat assistant → "Smart Search Assistant"
- OSINT panel → "OSINT/SEO Smart Assistant"
- "Powered by Truegle AI" → "Powered by Truegle Search"
- SearchBar category `ai` → `smart`
- LandingPage feature card → "Source Identification & Insights"

### 2. 3-Way Pill Toggle (Blue → Red → Green → Blue)
`SearchBar.jsx` PillToggle now cycles through all three modes seamlessly.
Each click advances to the next: Blue → Red (warning modal) → Green → Blue.
`UniversalSearch.jsx` `handlePillModeChange` accepts both string mode and legacy boolean.

### 3. Green Pill Mode — AI-Free Search
- URL: `/search?mode=green`
- Background: `LetterGlitch` canvas animation (`#2b4539`, `#61dca3`, `#61b3dc` palette)
- Component: `apps/frontend/src/components/backgrounds/LetterGlitch.jsx`
- Smart features (summary, chat) auto-disabled in green mode
- Green-themed result cards and borders

### 4. Search Summary Banner
Replaced the always-visible AI Summary card with a minimal **thin banner** that appears after search:
- Default: banner with "Show Summary" / "No Summary" buttons
- "Show Summary" → expands full card for the session; can collapse/re-expand
- "No Summary" → confirmation modal ("disables summaries for this session")
- Session state stored in `sessionStorage` key `truegle_summary_choice`
- Banner hidden entirely in Green Pill mode

### 5. First-Search Modal
Fires **once per session** after the first query executes:
- Offers to switch to Green Pill Mode for an AI-free experience
- Session flag: `sessionStorage.truegle_first_search_done`

### 6. Tutorial Modal (`TutorialModal.jsx`)
5-step interactive walkthrough shown **once per device** (`localStorage.truegle_tutorial_done`):
1. Welcome — brand overview
2. Blue Pill — standard search
3. Red Pill — deep dive + token info
4. Green Pill — zero smart features
5. Search Summaries — how the banner works

Wired into `UniversalSearch.jsx`. Progress bar, Back/Next/Let's go navigation.

### 7. BiasedResults — Freemium Token System
Red Pill page (`/search?mode=purple` or legacy `/biased`) now has:
- **10 tokens per session**: searches cost 1 token, chat messages cost 1 token
- Token counter badge fixed top-right (turns red/pulse when ≤ 2)
- **Paywall modal** when tokens hit 0:
  - "Watch Ad for +5 Tokens" (button wired, ad integration TODO)
  - "Subscribe to Premium" → `/pricing`
- Session state: `sessionStorage.redPillTokens`

### 8. Auth Redirect Fix (SignIn + SignUp)
Both pages had broken post-login navigation — `/search?mode=red` was being rewritten to `/search-results?mode=red`.
Now simplified to:
1. If `redirectTo` present → navigate directly (no transformation)
2. If `fromOSINT` flag → `/search?mode=ocean`
3. If `fromBiased` flag → `/search?mode=purple`
4. Fallback → `/search?mode=red` (if red pill was active) or `/search`
