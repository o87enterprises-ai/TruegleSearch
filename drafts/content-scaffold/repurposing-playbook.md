# Repurposing playbook (Phase 4)

Turn one finished pillar/top post into a week of multi-platform content. All
tools listed are free-tier. Start with the highest-value asset you already have:
**`/privacy-resource-hub`** (the pillar), then the two AI-honesty posts (your
longest, most distinctive), then the expanded cluster posts.

For each source post, produce the four assets below. Keep the same core claims
as the post so nothing drifts — link back to the article everywhere.

---

## 1. YouTube video (10–15 min) — screen-recording + voiceover

**Free tools:** OBS Studio (record), any phone/USB mic, a free editor (DaVinci
Resolve free / CapCut).

**Script skeleton:**
- **Hook (0:00–0:20):** the sharpest question the post answers ("Two people search the same thing and get opposite results — here's why").
- **Promise (0:20–0:40):** what the viewer will be able to do by the end.
- **Body:** one segment per H2 of the post. Show, don't tell — screen-record the actual steps/searches.
- **Payoff / demo:** the concrete example from the post, performed live.
- **CTA (last 30s):** "Full write-up + links in the description → truegle.info/blog/<slug>" and "try it at truegle.info".

**Description:** first two lines = the post's meta description + the article
link. Then timestamps (one per H2). Then 3–5 keyword tags from the post.

**Thumbnail:** the hook as ≤5 words, high contrast. (Free: Canva.)

## 2. X / Twitter thread (15–25 posts, drip over 2–3 days)

**Structure:**
- **Post 1 (the hook):** the single most surprising line from the article. No link yet (algorithms suppress first-post links) — say "🧵" / "here's the breakdown".
- **Posts 2–N:** one idea per post. Convert each H2 into 2–4 posts. Lists become one bullet per post. Keep each self-contained and quotable.
- **Second-to-last:** the summary bullets, condensed.
- **Last post:** the CTA + the article link ("Full guide, with sources: truegle.info/blog/<slug>").

**Reuse:** each thread post is also a standalone LinkedIn/Mastodon/Bluesky post.

## 3. Podcast episode (audio) — Spotify for Podcasters (free hosting)

- Record the YouTube voiceover **without** needing the screen — the same script works as audio if you narrate the steps ("in your browser settings, you'll see…").
- 8–15 min. Intro (who/what), body (the post's sections), outro (CTA + "links in the show notes").
- **Show notes:** article link + the FAQ Q&As from the post (great for podcast SEO).

## 4. Short-form clips (30–60s) — TikTok / Reels / YouTube Shorts

- Pull **3–5 clips** from the long YouTube video: each = one self-contained tip or the single most surprising fact.
- Hard hook in the first 2 seconds (the question or the myth).
- Burn in captions (most viewers watch muted). Free: CapCut auto-captions.
- **Bio link** → the article or the homepage (you can't link per-clip, so say "link in bio").

---

## Per-post repurposing checklist

- [ ] Source post is finished and live.
- [ ] YouTube script drafted (one segment per H2).
- [ ] Video recorded + captioned + uploaded; description has the article link + timestamps.
- [ ] 3–5 shorts cut from the long video.
- [ ] X thread drafted (hook has no link; last post has the link) and scheduled.
- [ ] Podcast episode narrated + show notes include FAQ.
- [ ] Every asset links back to `truegle.info/blog/<slug>` (or the pillar).

## Suggested first sprint (one week)

| Day | Asset | Source |
|-----|-------|--------|
| Mon | Record + edit YouTube video | `/privacy-resource-hub` pillar |
| Tue | Cut 3–5 shorts from the video | same |
| Wed | Draft + schedule X thread | same |
| Thu | Record podcast + show notes | same |
| Fri | Repeat step 1 for the next post | `ai-honesty-test-documented-facts` |

Rinse and repeat, one source post per week, working down the expanded posts and
then the new long-tail posts as they ship.
