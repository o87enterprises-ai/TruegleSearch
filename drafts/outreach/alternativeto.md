## Short description (one line)

Private metasearch engine that combines several providers and labels each result by source.

## Long description (starting point; edit it)

Truegle is a search engine that does not profile you. It queries several search providers at once, including Brave, from its own server, so the providers see Truegle and not you, and it labels results by the source they came from. It carries no ads and sets no cookies.

You can switch between lenses to see the same query framed differently: a mainstream view, an independent and alternative view, a privacy and OSINT view, or a zero-AI mode that calls no model at all. It also has a video and audio player (True Tube), a feed that reads your social accounts without posting, and OSINT lookups.

Limits: it is a young, one-developer project (founded in 2025) with no web index of its own, so it depends on the providers it combines. Providers can see the query text. Ordinary searches are kept as an anonymous line, with no account and no IP, for at most 7 days to show what is trending.
