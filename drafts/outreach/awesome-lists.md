# Awesome privacy lists (GitHub CLI works)

## Read this first: Truegle may not qualify yet

[Lissy93/awesome-privacy](https://github.com/Lissy93/awesome-privacy/blob/main/.github/CONTRIBUTING.md) is the biggest list and has strict rules (quoted from its CONTRIBUTING.md at the time of writing):

- Needs an **open-source license** (the LICENSE PR covers this).
- **Mature:** "Repositories must not be newly created, and the first stable release older than 4 months." Check the repo's first-commit date and your first stable release before applying.
- "Projects that are largely AI/autogenerated without meaningful review or maintainership are not suitable." Truegle has been built with heavy AI assistance, so be ready to say honestly who reviews and maintains it.
- **Descriptions and PR text must be human-written.** AI may help with the YAML, but "if AI has been used substantially while preparing a PR, this should be clearly disclosed." So: write the description yourself. The draft below is only facts and structure.
- You must **declare you are the author** of the project.
- Description must be **50-250 characters**, objective, with drawbacks as well as strengths.
- One addition per PR; PR title format `Adds Truegle to Search Engines`; fill in the PR template; reply to review comments within 14 days.
- Low-effort self-promotion PRs "may be closed without feedback." If maturity is borderline, the file says exceptions go in a "Notable Mentions" section instead.

If you are unsure you meet the maturity and maintenance bar, wait. A rejected or closed PR is a worse first impression than no PR.

## CLI steps (PowerShell)

```powershell
gh repo fork Lissy93/awesome-privacy --clone --default-branch-only
cd awesome-privacy
git checkout -b add-truegle
# edit awesome-privacy.yml: add the entry at the bottom of the Search Engines services
# validate if you have make (WSL/Git Bash): make validate   (CI validates it too)
git add awesome-privacy.yml
git commit -m "Adds Truegle to Search Engines"
git push -u origin add-truegle
gh pr create --repo Lissy93/awesome-privacy --title "Adds Truegle to Search Engines" --body-file pr-body.md
```

`pr-body.md` must follow their PR template (`.github/PULL_REQUEST_TEMPLATE.md`), say you are the author, and disclose any AI help. Write it yourself.
